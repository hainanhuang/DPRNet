## Rules

- Keep one journal's manuscript, source archive, cover letter, declarations,
  metadata, and local upload instructions in that journal's directory.
- Do not reuse a cover letter across package directories.
- Historical packages 01--03 are records of completed submission attempts.
- The Neurocomputing package also contains its full source distribution and
  distribution ZIP under `distribution/`.
- Package 04 is the active submission. Its Springer submission ID and current
  status are recorded in `submission_confirmation.txt`.
- Build scripts in the parent `paper/` directory write directly to these
  package directories.
